# docs

Keep the study's written records here, so they are versioned with the code:

- `decisions.md`: the nine design decisions approved by your chair (plan section 2), with dates
- `parameters.md`: frozen monitor parameters (T1, T2, kappa, lambda) and the calibration result
- `preregistration.md`: the analysis plan as posted on OSF, with its link
- `run-notes.md`: dated notes on failed runs, re-runs and anything unexpected
